Документация MUD¶

Этот пакет содержит клиент и сервер для простой многопользовательской текстовой игры MUD.

Сервер отвечает за игровое поле, монстров, игроков, атаки, локализацию и обмен сообщениями с подключёнными клиентами.

Клиент предоставляет интерактивный интерфейс командной строки для подключения к серверу и управления игроком.

Доступные команды клиента¶

Перемещение игрока¶

up
down
left
right

Описание команд:

  • up — переместиться вверх;

  • down — переместиться вниз;

  • left — переместиться влево;

  • right — переместиться вправо.

Добавление монстра¶

Формат команды:

addmon <monster_name> hello <message> hp <hp> coords <x> <y>

Пример:

addmon turtle hello "I am turtle" hp 10 coords 3 4

Атака монстра¶

Формат команды без указания оружия:

attack <monster_name>

Формат команды с указанием оружия:

attack <monster_name> with <weapon>

Доступное оружие:

  • spear;

  • axe;

  • sword.

Сообщение всем игрокам¶

sayall <message>

Включение и выключение движения монстров¶

movemonsters on
movemonsters off

Смена локали¶

locale <locale>

Пример:

locale ru_RU.UTF8

Открытие документации¶

documentation

Команда documentation открывает сгенерированную HTML-документацию в браузере с помощью функции webbrowser.open().

Завершение работы клиента¶

exit

Также завершить работу клиента можно сочетанием клавиш Ctrl+D.
