Документация MUD
================

Этот пакет содержит клиент и сервер для простой многопользовательской
текстовой игры MUD.

Сервер отвечает за игровое поле, монстров, игроков, атаки, локализацию
и обмен сообщениями с подключёнными клиентами.

Клиент предоставляет интерактивный интерфейс командной строки для подключения
к серверу и управления игроком.

Доступные команды клиента
=========================

Перемещение игрока
------------------

.. code-block:: text

   up
   down
   left
   right

Описание команд:

* ``up`` — переместиться вверх;
* ``down`` — переместиться вниз;
* ``left`` — переместиться влево;
* ``right`` — переместиться вправо.

Добавление монстра
------------------

Формат команды:

.. code-block:: text

   addmon <monster_name> hello <message> hp <hp> coords <x> <y>

Пример:

.. code-block:: text

   addmon turtle hello "I am turtle" hp 10 coords 3 4

Атака монстра
-------------

Формат команды без указания оружия:

.. code-block:: text

   attack <monster_name>

Формат команды с указанием оружия:

.. code-block:: text

   attack <monster_name> with <weapon>

Доступное оружие:

* ``spear``;
* ``axe``;
* ``sword``.

Сообщение всем игрокам
----------------------

.. code-block:: text

   sayall <message>

Включение и выключение движения монстров
----------------------------------------

.. code-block:: text

   movemonsters on
   movemonsters off

Смена локали
------------

.. code-block:: text

   locale <locale>

Пример:

.. code-block:: text

   locale ru_RU.UTF8

Открытие документации
---------------------

.. code-block:: text

   documentation

Команда ``documentation`` открывает сгенерированную HTML-документацию
в браузере с помощью функции ``webbrowser.open()``.

Завершение работы клиента
-------------------------

.. code-block:: text

   exit

Также завершить работу клиента можно сочетанием клавиш ``Ctrl+D``.
